# Real-Time Disaster Response System with Geospatial Data

This project demonstrates how data science, specifically predictive analytics, can be used in disaster management. By simulating real-time disaster data, we showcase how geospatial analysis can aid in disaster preparedness and response. The project uses Python libraries like `pandas`, `geopandas`, `shapely`, and `matplotlib` to create a simplified map visualization of disaster locations and corresponding response plans.


## Introduction

The **Real-Time Disaster Response System with Geospatial Data** project simulates a basic disaster management system using predictive analytics. It visualizes disaster events on a simplified world map, categorizes them by severity, and outlines a corresponding response plan. The project does not require external datasets, as all data is generated within the script.

## Project Structure

The project consists of the following files:

- `project.py`: The main Python script that runs the disaster management simulation.
- `README.md`: This file, providing an overview and instructions for the project.

## Installation

To run this project, you'll need to have Python installed along with the required libraries. You can install the necessary libraries using the following commands:


pip install pandas geopandas shapely matplotlib

## Usage
Clone the repository or download the project.py script to your local machine.

## Run the script:

python project.py
The script will generate a map displaying disaster response locations and print a table summarizing the disaster events and the planned responses.
